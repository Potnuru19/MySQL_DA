SET OPERATORS:
-----------------

UNION:
Combine results from two queries and removes duplicates rows. columns must have the same number and type.

UNION ALL:
Combines results from two queries and include all rows. including duplicates. columns must have the same
number and type.

INTERSECT:
Returns rows that are common to both queries. columns must have the same number and type.
Note: MySQL Doesn't support intersect directly.

MINUS/EXCEPT:
Returns rows from the first query that are not present in the second query. columns must have the same 
number and type.

JOINS:
=======
A join in MySQL is used to combine rows from two or more tables based on related columns.

example:
--------
employees table---> employee details
department table---> department details

if you want to see which employee belongings to which department. You need to join these two tables.

Why do we need joins:
----------------------
1. To fetch data from multiple tables in a single query.
2. To reduce data duplication(instead of keeping everything in one table).
3. To implement relationships like(One-to-One, One-to-Many, Many-To-One, Many-to-Many).
4. To generate reports and analytics combining different datasets.

Types of Joins:
----------------
1) Inner join:
Return only the rows that have matching values in both tables.
Syntax:
--------
select columns
from table1
inner join table2
on table.common_common=table2.common_column;

SELECT*FROM TAB1
    -> INNER JOIN TAB2
    -> ON TAB1.NUMID=TAB2.NUMID;


2) Left Join:
Returns all rows from the left table and the matched rows from the right table if no match
null values appear for the right table columns.
Syntax:
--------
select columns
from table1
left join table_2
on table.common_column=table2.common_column;

SELECT*FROM TAB1
    -> LEFT JOIN TAB2
    -> ON TAB1.NUMID=TAB2.NUMID;


3) Right Join:
Returns all rows from the right table and the matched rows from the left table if no match
null values appear for the left table columns.
Syntax:
-------
select columns
from table1
right join table_2
on table.common_column=table2.common_column;

SELECT*FROM TAB1
    -> RIGHT JOIN TAB2
    -> ON TAB1.NUMID=TAB2.NUMID;


4) Full Join:
To simulate the use the UNION of LEFT JOIN and RIGHT JOIN.
Syntax:
--------
select columns
from table1
left join table2
on table1.column_column=table2.common_column
UNION
select columns
from table1
right join table2
on table1.common_column=table2.common_column;

SELECT*FROM TAB1
    -> LEFT JOIN TAB2
    -> ON TAB1.NUMID=TAB2.NUMID
    -> UNION
    -> SELECT*FROM TAB1
    -> RIGHT JOIN TAB2
    -> ON TAB1.NUMID=TAB2.NUMID;


5) Cross Join:
Returns cartesian product --> every row from the first table with every row from the second
table.
Syntax:
--------
select columns
from table1
cross join table2;

SELECT*FROM TAB1 CROSS JOIN TAB2

6) Self Join:
A table joined with itself.
Syntax:
--------
select a.columns,b.columns
from table1 a
inner join table1 b
on a.common_column=b.common_column;
